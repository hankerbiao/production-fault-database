# 数据源一致性比对功能实施计划

**目标：** 在同步管理页控制工位过站 HANA 与 MongoDB 的每日一致性比对，并在发现差异时通过光圈通知。

**架构：** Python 只读比对脚本按当前销售订单范围分批读取 HANA 和 MongoDB；Go 后端持久化配置与运行记录、提供 API 并在每日配置时间启动脚本；React 页面提供开关、手动运行和历史结果。

**技术栈：** Python、hdbcli、PyMongo、Go、MongoDB、React。

---

### 组件

1. 新增工位过站只读比对脚本，比较缺失、多余、重复和字段差异，并用服务端环境变量配置光圈通知。
2. 增加 MongoDB 配置及运行记录存取，后端提供读取/更新配置、手动执行、读取历史接口。
3. 增加每日调度器，基于持久化运行记录和唯一日任务 ID 防止重复触发。
4. 同步管理页展示配置、执行控制和比对结果摘要。
5. 更新环境变量示例及同步文档。

验证限制：遵守本任务执行环境约束，不新增或运行测试。
