# 机器配置查询接口

`GET /api/machines/config/5000` 按整机 SN 查询该机器的物料配置。接口先从本地工位视图 `Z_V_ZMES_T_001` 解析生产订单号 AUFNR，再按 AUFNR 查询订单 BOM 过账明细视图 `ZSGV_ZSD124`，按物料汇总后输出与 stepsmanagement `queryMaterialByOrderID` 兼容的数组结构。

数据来自已同步到本地 MongoDB 的视图，不是 SAP / KK 实时查询；数据新鲜度取决于对应视图的同步状态。网关本身没有认证、授权或限流，生产环境应放在可信网络或由上游网关保护。

## 请求

- 方法：`GET`
- 路径：`/api/machines/config/5000`
- 参数位置：Query String
- 请求体：无

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `sn` | string | 是 | 整机序列号，精确匹配工位视图 `Z_V_ZMES_T_001.PCODE`。长度 1–40，不能包含空格、制表符或换行；前后空白会被去掉。 |

示例：

```bash
curl -sS "http://10.17.150.235:18080/api/machines/config/5000?sn=6102310604796170"
```

前端入口 `http://10.17.150.235:5174/` 会将 `/api` 代理到同一后端，也可以直接访问：

```bash
curl -sS "http://10.17.150.235:5174/api/machines/config/5000?sn=6102299104767755"
```

### 请求校验与状态码

| 状态码 | 场景 | 响应示例 |
| --- | --- | --- |
| `200` | 查询成功。即使订单没有物料明细，也返回空数组。 | `[]` |
| `400` | 缺少 `sn`；`sn` 超过 40 字符；`sn` 含空白字符。 | `{"error":"缺少 sn 参数"}` |
| `404` | 工位视图中没有该 SN 的工位记录，或所有记录的 AUFNR 为空。 | `{"error":"未找到 SN 9999999999999999 对应的生产订单"}` |
| `500` | MongoDB 查询失败。 | `{"error":"..."}` |

## 响应

成功时直接返回 JSON 数组，每项代表一个物料在该生产订单内的净发料汇总。数组按 `type`、`name`、`dn` 升序排序。没有外层 `items` / `total` 包装。

单项结构示例（以 SN `6102310604796170` 的第一项为例，实际响应共 20 项）：

```json

    "id": "local-30240235-B6200004",

    "params": [
      {
        "id": "local-30240235-B6200004-model",
        "orderId": 30240235,
```

### 顶层字段

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `needNum` | number \| null | stepsmanagement 上游的需求数量。本地工位/BOM 数据没有对应来源，固定返回 `null`。 | `null` |
| `num` | number | 单机数量：`totalNum / PSMNG`，即订单净发料量除以订单台数。保留最多 4 位小数；发料未齐时可能是小数；`PSMNG` 缺失或不大于 0 时为 `0`。 | `2` |
| `totalNum` | number | 该物料在本生产订单内的有符号净发料总量。`BWART=261` 发料为正，`BWART=262` 退料为负；汇总后只保留净量为正的物料。 | `146` |
| `name` | string | 物料描述，取 BOM 过账明细的 `MAKTX`。 | `Intel 8457C 2.6G 97.5M 48C 350W LJS(B02)` |
| `materialgroup` | string | 物料组 `MATKL`，用于部件分类和排除非机器配置物料。 | `620002` |
| `dn` | string | 物料号，优先取 `MATNR_BI`，为空时取 `MATNR`，并去掉前导零。同一物料号在订单内汇总为一项。 | `B6200004` |
| `relationId` | string | 本地生成的代理关联键，格式 `local-<物料号>`。**不是** stepsmanagement 原始 `relationId`。 | `local-B6200004` |
| `id` | string | 本地生成的代理主键，格式 `local-<生产订单号>-<物料号>`。**不是** stepsmanagement 原始 `id`。 | `local-30240235-B6200004` |
| `type` | string | 由物料组映射的 steps 部件类型代码；未映射的物料组返回空字符串。映射见下文。 | `CPU` |
| `params` | array | 该物料的参数键值对，可能包含“型号”和“库位”，也可能为空数组。结构见下表。 | `[...]` |

### `params[]` 字段

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `id` | string | 参数代理主键，格式 `local-<生产订单号>-<物料号>-<参数后缀>`；后缀为 `model` 或 `location`。 | `local-30240235-B6200004-model` |
| `orderId` | integer | 物料归属的生产订单号 AUFNR，数值类型。 | `30240235` |
| `relationId` | string | 参数所属物料的代理关联键，与顶层 `relationId` 一致。 | `local-B6200004` |
| `materialSn` | string | 参数所属物料的物料号，与顶层 `dn` 一致。 | `B6200004` |
| `comparionValue` | string | 参数值。型号参数为从物料描述中提取的型号，库位参数为 `LGORT`。字段名沿用 stepsmanagement 原拼写 `comparionValue`（不是 `comparisonValue`）。 | `8457C` / `9N00` |
| `name` | string | 参数名，目前只有 `型号` 和 `库位`。 | `型号` |
| `partsDescription` | string | 物料所属部件类别的中文描述，取 `WGBEZ`，如处理器、电源模块、线缆。 | `Intel CPU` |
| `materialGroup` | string | 参数所属物料的物料组，与顶层 `materialgroup` 一致。 | `620002` |

`params` 不是固定两条：

- “库位”参数在 `LGORT` 非空时输出，取该物料第一条过账记录的库位；不按多库位拆分。
- “型号”参数只在处理器、内存、硬盘/存储、电源模块、风扇、机箱、部分网卡等物料组尝试输出；从物料描述中按启发式规则提取。主板、其他部件、线缆等不输出型号。
- 提取不到型号时只输出库位；两者都为空时 `params` 为 `[]`。

## 取值口径

### 1. SN → 生产订单

1. 用 `sn` 精确查询工位视图 `Z_V_ZMES_T_001` 的 `PCODE` 字段，最多取 100 条。
2. 从所有非空 `AUFNR` 中选择 `GSTRS` 最大（最新）的一条，去掉 AUFNR 的前导零。
3. 找不到工位记录或 AUFNR 全为空时返回 `404`。

同一 SN 存在多条工位记录时只使用最新一条的 AUFNR；不合并多个订单。

### 2. 生产订单 → BOM 明细

1. 用 AUFNR 查询 BOM 过账视图 `ZSGV_ZSD124` 的 `AUFNR_1`，兼容去零和补零形式。
2. 每页 100 条分页读取全部记录，最多 100 页，即最多 10,000 条明细。不使用 `/all` 投影，因为该投影缺少 `MATKL`、`WGBEZ`。
3. 排除以下非机器配置物料组：
   - `520001` 包装材料
   - `520002` 标签标牌
   - `030005` 机箱附件（金属螺钉）
   - `030011` 机箱附件（非金属类）

### 3. 按物料汇总

1. 以物料号 `MATNR_BI` / `MATNR` 为键汇总。
2. 数量使用有符号 `MENGE`：`261` 发料为正，`262` 退料为负。不使用 `MENGE_A` 绝对值，避免退料被重复计算。
3. `totalNum` 为净发料总量；净量小于等于 0 的物料不输出。
4. `num = totalNum / PSMNG`，`PSMNG` 为该订单台数；`PSMNG` 不大于 0 时 `num=0`。
5. `params.partsDescription` 取该物料第一条记录的 `WGBEZ`，`params.comparionValue`（库位）取第一条记录的 `LGORT`。

### 4. 已知数据限制

- 单次查询最多等待 15 秒；超时会终止数据库读取并返回错误。
- BOM 明细最多读取 100 页、每页 100 条，即最多 10,000 条；超过上限时响应头会带 `X-Machine-BOM-Truncated: true`，表示结果可能不完整。
- 只覆盖已同步到本地 MongoDB 的工位记录和 BOM 过账记录；未同步、未过账或不在工位视图中的机器查不到配置。
- 工位视图没有该 SN 时返回 `404`，即使该 SN 在 SAP 中能查到库存信息。
- BOM 只包含已过账物料；订单存在但没有过账明细时返回 `[]`。
- `num` 可能为小数，表示订单发料尚未按台数配齐，不代表物料本身可按小数领用。
- 返回结构兼容 stepsmanagement，但不是其原始数据：`needNum` 恒为 `null`，`id` / `relationId` 及 `params[].id` 为本地代理键。
- 厂商信息未包含在本接口中；现有 `GET /api/hana/material-vendor?materialNumber=<物料号>` 可单独查询。
- `type` 只覆盖下表已登记物料组，其余为空字符串。前端按空字符串归入“未分类”。

## 部件类型映射

| 物料组 `MATKL` | `type` | 含义 |
| --- | --- | --- |
| `620001` / `620002` | `CPU` | 处理器 |
| `500001` | `MEM` | 内存 |
| `540009` / `540010` | `YP` | 硬盘 / 存储 |
| `240001` | `MB` | 主板 |
| `240023` / `240024` / `240007` | `NETC` | 网卡 |
| `240008` | `XK` | 显卡 |
| `330002` | `DYMK` | 电源模块 |
| `570001` | `JX` | 机箱 |
| `030002` | `FS` | 风扇模组 |
| `030001` / `030015` / `240010` / `240025` | `QTBK` | 其他部件 |
| `370001` / `370002` / `370003` | `XL` | 线缆 |

未列入上表的物料组照常参与汇总，但 `type` 为空字符串。
